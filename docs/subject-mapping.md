# Subject-wise Concept Mapping

## ISD — Information Systems Design
- Identify the problem, stakeholders and system scope.
- Functional and non-functional requirements.
- Use cases for student, alumni and admin.
- Context-level data-flow description.
- Relational entity/relationship design.
- Manual acceptance-test checklist.

## ASD — Advanced Software Development
- React component-based user interface.
- Node.js and Express REST API.
- HTTP GET, POST, PUT and PATCH methods.
- JWT authentication and role-based middleware.
- Async/await and centralized error handling.
- Environment-based configuration and modular source files.

## DBMS
- PostgreSQL relational tables.
- Primary keys, foreign keys and unique constraints.
- CHECK and NOT NULL constraints.
- One-to-one, one-to-many and many-to-many relationships.
- JOIN, GROUP BY, COUNT, SUM and indexes.
- Parameterized queries and CSV report extraction.

## DE — Data Engineering
- Structured alumni profile, career and opportunity records.
- Query-based data extraction from PostgreSQL.
- CSV export as a simple downstream data hand-off.
- Report summaries by role, opportunity type, mentorship status and pledge status.
- Future extension: scheduled ETL from institutional alumni records. The current prototype keeps data entry and export explicit rather than claiming an automated production ETL pipeline.
